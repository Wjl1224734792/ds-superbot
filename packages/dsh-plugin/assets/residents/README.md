# 在场头像（占位）

本目录的四张 SVG 仍是 **P0/P2 占位脸谱**，不是正式绘制。P2 已改成可分层 SVG（脸底、眼白、瞳孔、眼睑、眉），方便用 `.stwd-` 作用域样式做眨眼与眼神，但短名、目录名和 `presenceOf` 的状态代号不得更改。换正式脸谱时不得改这些契约。

| 脸 | 目录 | 能力 | 可辨认特征（占位） | 状态 |
| --- | --- | --- | --- | --- |
| 仓 | `cang/` | Steward，默认开口 | 青灰屋顶发形、青绿衣领、半睁的圆眼 | 占位（已分层） |
| 探 | `tan/` | Discover，只读取证 | 尖下巴、侧扫棕发、锈橙围巾、目光略偏 | 占位（已分层） |
| 作 | `zuo/` | Build，按文件所有权施工 | 方颌、短发加头带、微眯的眼、苔绿领 | 占位（已分层） |
| 验 | `yan/` | Verify，独立验证 | 圆脸、中分、椭圆眼镜、紫领 | 占位（已分层） |

这些是 ds-superbot 的原创几何简化脸，不是现成产品或模型品牌的形象。动画只能用 `.stwd-` 作用域样式，禁止引入 Lottie / Three.js / 视频库。正式绘制可以后补。
