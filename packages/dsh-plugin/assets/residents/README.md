# 在场头像（占位）

本目录的四张 SVG 是 **P0 占位脸谱**，不是正式绘制。换正式脸谱时不得改短名、目录名或 `presenceOf` 的状态代号。

| 脸 | 目录 | 能力 | 可辨认特征（占位） |
| --- | --- | --- | --- |
| 仓 | `cang/` | Steward，默认开口 | 青灰屋顶发形、青绿衣领、半睁的圆眼 |
| 探 | `tan/` | Discover，只读取证 | 尖下巴、侧扫棕发、锈橙围巾、目光略偏 |
| 作 | `zuo/` | Build，按文件所有权施工 | 方颌、短发加头带、微眯的眼、苔绿领 |
| 验 | `yan/` | Verify，独立验证 | 圆脸、中分、椭圆眼镜、紫领 |

这些是 ds-superbot 的原创几何简化脸，不是现成产品或模型品牌的形象。P2 再接到顶部迷你脸、右侧舞台和群聊气泡；动画只能用 `.stwd-` 作用域样式，禁止引入 Lottie / Three.js / 视频库。
