# 在场头像（正式原创脸谱）

本目录的四张 SVG 是 **正式原创脸谱**：几何/插画风角色肖像，供舞台与迷你脸使用。它们是 ds-superbot 的原创形象，不是任何现成产品、模型或第三方品牌的肖像。短名、目录名和 `presenceOf` 的状态代号不得更改。换皮不得改这些契约。

分层结构（脸底、眼白、瞳孔、眼睑、眉、衣领等）保持不变，方便用 `.stwd-` 作用域样式做眨眼与眼神。`viewBox` 仍是 `0 0 64 64`。动画只能用 `.stwd-` 作用域样式，禁止引入 Lottie / Three.js / 视频库或其它 npm 动画依赖。
